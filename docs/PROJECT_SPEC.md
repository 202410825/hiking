# PROJECT_SPEC.md — Hiking 상세 명세서

## 1. 프로젝트 개요

**Hiking**은 상명대학교(서울캠퍼스, 홍제역/부암동 인근) 학생과 지역주민을 위한 위치 기반 스탬프 수집 & 커뮤니티 플랫폼이다.

- **문제 정의**: 학생들이 수업이 끝나면 바로 귀가하거나 캠퍼스 밖으로 빠르게 이탈하면서, 학교 주변 상권이 활성화되지 못하고 학생들도 캠퍼스 인근의 좋은 장소(청계천, 경복궁, 부암동 카페거리 등)를 잘 탐방하지 않는다. 또한 캠퍼스 자체의 경사로가 많아 이동에 스트레스를 느끼는 학생이 많다.
- **해결 방향**: 특정 지점(교내 건물, 지역 상점, 관광지)에 도착해 QR/NFC/위치 인증을 하면 스탬프가 쌓이고, 일정 개수를 모으면 리워드로 교환할 수 있는 게이미피케이션 구조를 만든다. 동시에 장소별 리뷰·추천 커뮤니티를 붙여 정보 공유를 유도한다.

## 2. 타겟 사용자 및 페르소나

| 구분 | 설명 | 핵심 니즈 |
|---|---|---|
| 상명대 재학생 | 수업 사이 시간이 뜨거나 하교 후 갈 곳을 찾는 학생 | 스트레스 해소, 리워드, 친구와 같이 다니는 재미 |
| 지역주민 | 홍제/부암동 인근 거주자 | 동네 할인 혜택, 새로운 장소 발견 |
| 제휴 상점/기관 | 카페, 편의점, 사찰 등 스탬프 지점 제공자 | 방문객 유입, 홍보 |

## 3. 핵심 사용자 스토리

1. 학생으로서, 수업이 끝난 뒤 근처에 뭘 할지 몰라서 앱을 켜고 오늘의 추천 동선을 확인하고 싶다.
2. 학생으로서, 경사로가 부담스러워서 완만한 우회 경로가 있는지 지도에서 확인하고 싶다.
3. 학생으로서, 도착한 장소에서 QR을 찍어 스탬프를 모으고, 8개를 모으면 리워드로 바꾸고 싶다.
4. 지역주민으로서, 학교 근처 방문객에게 우리 가게를 스탬프 지점으로 노출시키고 방문 시 할인을 제공하고 싶다.
5. 사용자로서, 다른 사람이 남긴 리뷰(별점, 사진, 우회로 팁)를 보고 어디를 갈지 정하고 싶다.
6. 사용자로서, 카카오톡 플러스친구를 통해 스탬프 현황과 리워드 알림을 받고 싶다.

## 4. 기능 명세

### 4.1 스탬프 수집 시스템
- 인증 방식: **QR 코드**(1순위, MVP) → NFC(2단계) → 위치 기반 + 사진 인증(3단계, 부정 적립 방지용 보조 수단)
- 지점당 하루 1회 적립 제한 (부정 사용 방지)
- 스탬프는 "시즌" 단위로 관리 (예: 학기별). 시즌 종료 시 미교환 스탬프는 이월 정책 별도 결정 필요
- 스탬프 카드는 8칸을 기본 단위로 하되, 지점 카테고리별(교내/지역사회) 별도 카드 운영 가능

### 4.2 지도 & 추천 장소
- 지도 API: 카카오맵 API 사용 (한국 주소/POI 정확도)
- 카테고리: 식당&카페, 놀거리/엔터테인먼트, 산책로, 학교 내 건물, 관광지(경복궁, 광화문, 청계천 등)
- 지점 상세: 이름, 카테고리, 설명, 사진, 평균 별점, 리뷰 목록, 스탬프 인증 방법
- 경사로 우회 경로 안내: 교내 건물 간 이동 시 경사도가 낮은 경로를 우선 추천 (지도 레이어 또는 별도 안내 카드)

### 4.3 커뮤니티
- 장소별 리뷰 작성 (별점 1~5, 텍스트, 사진 최대 3장)
- 피드형 게시글 (오늘의 팁, 우회로 공유 등)
- 좋아요, 댓글
- 신고 기능 (부적절 게시물 관리)

### 4.4 카카오톡 연동
- 카카오 로그인으로 회원가입/로그인
- 카카오톡 채널(플러스친구) 추가 시 스탬프 적립/리워드 알림 발송
- 친구 초대 공유 (카카오톡 공유 API)

### 4.5 리워드 시스템
- 리워드 카탈로그: 커피 쿠폰, 편의점 과자, 배민 쿠폰, 10% 할인(선결제), 수뭉이 NFC 키링(운세), 책갈피 등
- 리워드 획득 조건: 스탬프 N개 달성 시 자동 지급 또는 사용자가 직접 교환
- 리워드 사용: 매장 제시용 바코드/코드 발급, 사용 완료 시 상태 변경

## 5. 비기능 요구사항
- **부정 적립 방지**: QR 주기적 갱신 또는 위치 검증 병행
- **개인정보 보호**: 위치 정보는 스탬프 인증 시점에만 수집, 실시간 상시 추적 금지
- **접근성**: 경사로/이동약자 관련 정보 제공이 프로젝트 취지이므로, 앱 자체도 접근성 가이드(명도 대비, 큰 터치 영역 등) 준수
- **성능**: 지도 화면 초기 로딩 3초 이내 목표

## 6. 화면 목록 (MVP 기준)
1. 온보딩/카카오 로그인
2. 홈 (스탬프 패스, 오늘의 추천 동선)
3. 지도 (지점 목록, 필터, 상세 카드)
4. QR 스캔
5. 커뮤니티 피드 / 리뷰 작성
6. 마이페이지 (보관함, 리워드 사용 내역, 통계)
7. 관리자용 지점/리워드 등록 화면 (제휴처 관리, 별도 우선순위 낮음)

## 7. 향후 논의 필요 항목
- 시즌/스탬프 유효기간 정책
- 지역 제휴처 컨택 및 정산 방식
- NFC 도입 시점과 단말기 보급 비용
